# Todo App 📝

A simple todo app built with HTML, CSS and JavaScript.

## Features
- ✅ Add tasks by clicking button or pressing Enter
- ✅ Delete tasks with ❌ button
- ✅ Tasks save permanently using localStorage
- ✅ Validates empty input
- ✅ Responsive clean design

- Functions & parameters
- Arrays & forEach
- localStorage
- JSON.stringify & JSON.parse
